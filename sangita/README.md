# Romantic Love Website for Sangita

A beautiful, single-page romantic website created with HTML, CSS, and JavaScript for my girlfriend Sangita.

## Features

- Elegant design with Sangita's favorite colors (blue, white, and light pink)
- Floating hearts background animation
- Personalized love message section
- "A Letter About Why I Love You" in letter format
- Interactive elements with smooth animations
- Responsive design that works on all devices

## Sections

1. Welcome Section - "Hi Sangita ❤️"
2. "My Heart to Yours" - Personal love message
3. "A Letter About Why I Love You" - Expandable love letter
4. Special Popup Message - Click button to reveal a special message

## How to View

Simply open `index.html` in any web browser to view the website.

## Customization

To personalize this website:
1. Replace the placeholder text with your own romantic messages
2. Update the reasons in the love letter
3. Add real photos if desired
4. Modify colors in `style.css` if needed
